Steam badge icons are optional local assets.

Place files under:

assets/badges/<appid>/level-1.png
assets/badges/<appid>/level-2.png
assets/badges/<appid>/level-3.png
assets/badges/<appid>/level-4.png
assets/badges/<appid>/level-5.png
assets/badges/<appid>/level-6.png

Supported extensions: png, webp, jpg, jpeg, gif.

If a game has no matching files, Steam-KaKaBase hides the badge module.
